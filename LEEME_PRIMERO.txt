-----------------------------------------------------

   sudo chown -R $USER:$USER learnmind-ai
   cd learnmind-ai

3. Configurar variables de entorno:
   
   cp .env.production .env

   - Todas las contraseñas (PostgreSQL, MongoDB, Redis, MinIO)

🛠️ COMANDOS ÚTILES POST-DEPLOYMENT
=============================================================================

Ver estado de servicios:
  docker-compose -f docker-compose.prod.yml ps

Ver logs en tiempo real:
  docker-compose -f docker-compose.prod.yml logs -f

Ver logs de un servicio específico:
  docker-compose -f docker-compose.prod.yml logs -f backend
  docker-compose -f docker-compose.prod.yml logs -f frontend
  docker-compose -f docker-compose.prod.yml logs -f nginx

Reiniciar un servicio:
  docker-compose -f docker-compose.prod.yml restart backend
  docker-compose -f docker-compose.prod.yml restart frontend

Detener todo:
  docker-compose -f docker-compose.prod.yml down

Iniciar todo:
  docker-compose -f docker-compose.prod.yml up -d

Health check:
  curl https://learnmind-ai.jkhoster.com/api/health

Backup de base de datos:
  docker-compose -f docker-compose.prod.yml exec postgres \
    pg_dump -U learnmind_user learnmind_production > backup.sql
